## Каталог фильмов с избранным и фильтрацией (HW_1)

### Функциональность

- **Список фильмов**
  - Список фильмов захардкожен в коде в `App.tsx`.
  - Каждый фильм имеет поля: `id`, `title`, `year`, `posterUrl`, `isFavorite`.

- **Отображение фильмов**
  - Карточки фильмов рендерятся циклом (`map`).
  - Если после фильтрации фильмов нет — показывается текст **«Фильмов нет»**.

- **Избранное**
  - У каждой карточки есть кнопка со звездой ⭐.
  - Клик по кнопке переключает поле `isFavorite` через `useState`.

- **Фильтрация по избранному**
  - В верхней панели есть кнопки:
    - `Все`;
    - `Только избранные`.
  - Фильтрует список по полю `isFavorite`.

- **Поиск по названию**
  - Поле ввода `<input>` для поиска по названию фильма.
  - Значение инпута хранится в `useRef`, а не в состоянии.
  - Фильтрация по `title` без учета регистра.

- **Переключение режима отображения**
  - Переключатель вида: **плитка** / **список**.
  - В зависимости от выбранного режима меняется верстка и стили карточек.

### Стек

- React 18 (функциональные компоненты)
- TypeScript (строгая типизация)
- Vite

### Структура проекта (основные файлы)

- `index.html` — корневой HTML-файл.
- `vite.config.ts` — конфигурация Vite.
- `tsconfig.json` — конфигурация TypeScript.
- `src/main.tsx` — точка входа, монтирование приложения в DOM.
- `src/App.tsx` — основная логика приложения (фильмы, фильтры, поиск, переключение вида).
- `src/components/MovieCard.tsx` — компонент карточки фильма.
- `src/types.ts` — общие типы (`Movie`, `ViewMode`, `FavoriteFilter`).
- `src/styles.css` — стили и оформление интерфейса.

### Как запустить

Требуется установленный **Node.js** (желательно актуальная LTS-версия).

1. Клонировать/распаковать проект и перейти в его папку
2. Установить зависимости:

   ```bash
   npm install
   ```

3. Запустить dev-сервер:

   ```bash
   npm run dev
   ```

4. Открыть в браузере адрес, который покажет Vite (по умолчанию это обычно `http://localhost:5173/`).
