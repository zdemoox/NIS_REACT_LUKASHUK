# E-commerce Admin SPA

Административная панель для e-commerce системы на `React + TypeScript` с поддержкой аутентификации, каталога товаров, настроек приложения и интернационализации.

## Функциональность

- **Аутентификация**
  - Страница логина `/login`
  - Авторизация по логину и паролю
  - Хранение токена и данных пользователя в Redux
  - Logout и очистка состояния (`/logout` и кнопка на странице профиля)

- **Маршрутизация и layout**
  - Публичные маршруты: `/login`, `/register`
  - Приватные маршруты: `/` (Dashboard), `/products`, `/products/:id`, `/profile`, `/settings`, `/logout`, `*` (404)
  - Protected routes (без токена доступ к приватным страницам запрещён)
  - Общий layout для приватной части (sidebar + header)
  - Lazy loading страниц через `React.lazy`

- **Каталог продуктов**
  - Список продуктов `/products`
  - Детальная страница продукта `/products/:id`
  - Поиск по названию (через query-параметр `q`)
  - Пагинация через `limit / skip` и query-параметр `page`
  - Отображение цены, рейтинга и категории

- **Профиль пользователя**
  - Просмотр имени и email текущего пользователя
  - Выход из системы с очисткой Redux-состояния

- **Настройки приложения**
  - Язык интерфейса: ru / en
  - Тема: light / dark
  - Размер страницы каталога: произвольное число
  - Настройки хранятся в Redux и **persist** в `localStorage`
  - Переключение языка без перезагрузки страницы

- **Интернационализация (i18n)**
  - Два языка: русский и английский
  - JSON-файлы переводов для всех основных страниц, форм и состояний (ошибки, пустые списки и т.п.)
  - Поддержка переключения языка из настроек

## Архитектура проекта

Проект реализован в стиле Feature-Sliced Design с разделением по слоям:

```text
src/
 ├── app/        # инициализация приложения (store, router)
 ├── pages/      # страницы (роуты)
 ├── widgets/    # крупные UI-блоки (layout и т.п.)
 ├── features/   # (зарезервировано под бизнес-фичи)
 ├── entities/   # доменные сущности (auth, settings)
 └── shared/     # переиспользуемые модули и UI
```

- **`app/`**
  - `store.ts` — конфигурация Redux Toolkit + RTK Query + `redux-persist`
  - `router.tsx` — маршрутизация, protected-пути и lazy-загрузка страниц

- **`entities/`**
  - `auth` — `authSlice` с токеном и пользователем
  - `settings` — `settingsSlice` (тема, язык, размер страницы каталога)

- **`shared/`**
  - `api/dummyApi.ts` — RTK Query API для DummyJSON (`/auth/login`, `/auth/me`, `/products`, `/products/:id`, `/products/search`)
  - `config/i18n` — настройка i18next + JSON-файлы локализаций
  - `lib/hooks.ts` — типизированные `useAppDispatch` / `useAppSelector`
  - `ui/ThemeProvider.tsx` — применение темы через `data-theme`
  - `styles/index.css` — базовые стили, layout, карточки, формы

- **`pages/`**
  - `login` — форма логина, работа через RTK Query
  - `register` — заглушка регистрации
  - `dashboard` — простой дашборд
  - `products` — список + поиск + пагинация
  - `product-details` — детальная страница товара
  - `profile` — профиль текущего пользователя
  - `settings` — настройки темы/языка/пагинации
  - `logout` — страница выхода
  - `not-found` — 404

Бизнес-логика (запросы, хранение данных, настройки) вынесена в Redux Toolkit + RTK Query и слои `entities`/`shared`, компоненты страниц остаются тонкими.

## Запуск проекта

- **Требования**
  - Node.js 18+
  - npm 9+ (или совместимая версия)

- **Установка зависимостей**
  - В корне проекта выполнить:
    - `npm install`

- **Dev-сервер**
  - Запуск:
    - `npm run dev`
  - По умолчанию приложение доступно по адресу `http://localhost:5173/`
